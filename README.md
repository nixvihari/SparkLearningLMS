Spark Learning Cloud LMS is a prototype featuring core architectural and app functionality of an LMS platform. 


This prototype demonstrates student, teacher and admin user flows and offers the following features.

- Students will be able to enroll, access course materials and submit assignments.
- Teachers will be able to create courses, Add course materials and create new assignments.
- Admin assumes management control over data through a dashboard with tables and forms to add, update, delete or view all database records.
